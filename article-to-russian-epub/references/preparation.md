# Подготовка к переводу

Переводчик с опытом сначала разбирается в тексте и его контексте, а потом садится переводить. Результат подготовки — `brief.md` в папке статьи. Все последующие стадии опираются на него.

Для поиска использовать `parallel-cli search "<запрос>"` или веб-поиск самого агента. Запросы по-русски находят изданные переводы и устоявшиеся термины; по-английски — контекст оригинала.

## Структура `brief.md`

### Паспорт текста

Автор и кто он, жанр, площадка, аудитория оригинала, цель текста, аудитория перевода.

### Голос автора

Пять строк: длина фраз, ритм, лексика (сленг, профессиональный жаргон, книжность), юмор, степень резкости, отношение к читателю. Затем — русский ориентир: как звучал бы русский автор той же ниши (например, «умный телеграм-блогер о саморазвитии, а не переводная книга по психологии»). Форма обращения: «вы» или «ты», с обоснованием.

### Стратегия адаптации

Одна из двух, с обоснованием:

- **Перенос на русскую почву** — по умолчанию для блогов, научпопа, саморазвития, бизнеса: читатель не должен спотыкаться о чужие реалии.
- **Сохранение чужого** — для текстов, где сама культура оригинала и есть предмет: эссе о стране, репортаж, мемуары.

### Реалии

Таблица по всем культурно-специфичным элементам: бытовым реалиям, институтам, политике, спорту, поп-культуре, мемам, рабочему распорядку, единицам и форматам.

| Реалия | Решение | Русский вариант |
| - | - | - |
| dead-end job | заменить | «работа без перспектив» |
| retire at 65 | оставить | «выйти на пенсию в 65» |

Решение — одно из трёх: *оставить* (понятно без пояснений), *пояснить* (коротко, внутри фразы, без сносок), *заменить* (функциональным русским аналогом). Решения согласовать со стратегией адаптации.

### Цитаты и источники

Для каждой цитаты и упомянутой книги найти изданный русский перевод: «<автор> <название> русский перевод», затем саму цитату по ключевым словам. Если перевод найден — взять текст издания и записать источник (книга, переводчик, издательство). Если нет — переводить самостоятельно и отметить «перевод наш».

### Глоссарий

Если в рабочей папке есть `glossaries/<автор>.md` — загрузить его первым и следовать ему: он хранит решения из прошлых статей автора. Отступить от него можно только с обоснованием в таблице; при обновлении глоссария на стадии 9 такое отступление заменяет прежний вариант. Затем для каждого термина, ключевого понятия и повторяющейся фразы автора:

| Термин | Перевод | Обоснование |
| - | - | - |
| agency | субъектность | устоявшийся термин в русской психологии; при первом упоминании пояснить |

Обоснование — источник (профильная литература, изданный перевод) или причина выбора. Названия моделей, школ и теорий брать в принятом русском написании.

### Трудные места

Для названия статьи, заголовков разделов, афоризмов, шуток, игры слов и последней фразы — по 3–5 вариантов и рекомендация с одной строкой обоснования. Варианты должны различаться подходом, а не синонимами: буквальный, функциональный, вольный.

## Готовность

Подготовка завершена, когда в `brief.md` заполнены все разделы, каждая цитата имеет источник или отметку «перевод наш», каждая реалия текста имеет решение, а у названия и каждого заголовка есть рекомендованный вариант.
